■サービス概要
「過去の自分に説教する」をテーマにした自分史年表アプリ。
過去の失敗や後悔した出来事を記録し、「当時の自分へのアドバイス」を書き残すことで、成長を実感し、未来の自分に活かせる。
さらに、他のユーザーと共有し共感を得たり、学び合うことで、失敗からの成長を支援する。

■ このサービスへの思い・作りたい理由
きっかけは、母が「自分の人生を振り返る年表が欲しい」と言ったこと。
それを考えたとき、人は誰しも「やらかした…」「あの時こうすればよかった…」という経験があることに気づいた。
しかし、その経験を振り返らなければ、同じ失敗を繰り返す可能性が高い。
このサービスは、「過去の自分に説教することで、自分の成長を可視化する」ことを目的とする。
さらに、他のユーザーと経験を共有し、学び合うことで、自己成長を促進する。

■ ユーザー層について
自分の成長を記録したい人
過去の失敗を振り返り、「自分は成長した！」と実感したい人
他の人の失敗談から学びたい人
「似たようなミスをしないように、他の人の失敗談を読んで学びたい」人

■サービスの利用イメージ
ユーザーが過去の失敗や気づきを記録し、それをもとに振り返りやフィードバックを行うことで成長をサポートする。
フォロー機能など、他のユーザーと失敗を共有できる
